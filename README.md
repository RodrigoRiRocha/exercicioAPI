Meu Perfil do GitHub - Consumo de API com Fetch e jQuery

Este projeto exibe informações do perfil do GitHub consumindo a API pública do GitHub utilizando Fetch API e jQuery.

📌 Tecnologias Utilizadas

HTML5 → Estrutura da página

CSS3 → Estilização do layout

JavaScript  → Lógica para buscar e exibir os dados

jQuery → Manipulação do DOM

Fetch API → Comunicação com a API do GitHub

🎯 Funcionalidades

Exibir nome, username, avatar, número de repositórios, seguidores e seguindo.

Link direto para o perfil do GitHub.

Caso algum dado não esteja disponível, exibir um valor padrão.
